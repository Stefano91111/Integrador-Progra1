# Sistema de Control de Inventario

Sistema desarrollado en Python para administrar
el inventario de una ferretería.

## Funcionalidades

- Cargar herramientas.
- Mostrar inventario.
- Consultar productos.
- Identificar herramientas sin stock.
- Agregar herramientas.
- Registrar ventas e ingresos.

## Requisitos

- Python 3.13.15

## Ejecución

Ejecutar el archivo main.py:

python main.py

## Almacenamiento

Los datos se mantienen en memoria durante
la ejecución del programa. No se guardan
al cerrar la aplicación.
